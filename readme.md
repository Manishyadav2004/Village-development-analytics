# 📊 Village Dashboard – Data Visualization Project

## 📌 Overview
A Power BI dashboard focused on **percentage-based insights** using **KPI cards, Pie Charts, and Donut Charts** for clear and quick decision-making.

---

## 🛠️ Tools
- Power BI  
- DAX  
- Data Modeling  

---

## 📈 Dashboard Highlights
- **KPI Cards**: Key metrics (Population, Literacy %, Employment %, Resources %)  
- **Pie Charts**: Category-wise distribution in %  
- **Donut Charts**: Segmented percentage breakdown  
- **Filters**: Dynamic selection (village/category)  

---

## 📊 Key Focus
- All visuals represented in **percentage format**  
- Clean, interactive, and easy-to-understand layout  

---

## 🚀 How to Use
1. Open `.pbix` in Power BI Desktop  
2. Use filters to explore insights
