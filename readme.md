# 📊 Visualisation of Village Data

## Village Development Analytics Using Python & Power BI

A comprehensive **Village Development Analytics and Data Visualization** project that combines **Python-based data analysis** with an interactive **Microsoft Power BI dashboard** to analyze household-level village survey data.

The project converts raw survey responses into meaningful development indicators and visual insights covering **socio-economic conditions, healthcare, education, digital literacy, water and sanitation, environmental conditions, women empowerment, skills, livelihoods, migration, government schemes, and village governance**.

---

# 📌 Project Overview

This project follows an end-to-end data analytics workflow, starting from raw household survey data and ending with an interactive Power BI dashboard.

The project has two major components:

### 🐍 Python Data Analysis

Python is used for:

- Data loading
- Data inspection
- Data cleaning
- Data type handling
- Missing-value analysis
- Exploratory Data Analysis (EDA)
- Percentage-based analysis
- Development indicator analysis
- Cross-tabulation
- Relationship analysis
- Gap analysis
- Data visualization

### 📊 Power BI Dashboard

Power BI is used for:

- Data modeling
- DAX calculations
- KPI cards
- Pie charts
- Donut charts
- Percentage-based visualizations
- Interactive filters and slicers
- Village-level comparison
- Dashboard reporting

---

# 🎯 Project Objectives

The primary objectives of this project are:

1. Analyze household-level village survey data.
2. Understand the socio-economic profile of households.
3. Analyze income and occupational patterns.
4. Examine healthcare accessibility and health outcomes.
5. Analyze literacy, school enrollment and dropout patterns.
6. Examine digital access and the digital divide.
7. Evaluate water, sanitation and hygiene conditions.
8. Analyze environmental conditions and disaster vulnerability.
9. Study women's economic participation and decision-making.
10. Examine skill requirements and livelihood conditions.
11. Analyze employment-related migration.
12. Examine awareness and availability/utilization of government schemes.
13. Study awareness and participation in village governance.
14. Develop measurable village development indicators.
15. Identify development gaps through cross-tabulation and comparative analysis.
16. Present the analysis through an interactive Power BI dashboard.

# 📊 Dataset

The Python analysis uses household-level village survey data containing:

- **855 records**
- **75 variables**

The dataset covers multiple dimensions of village development.
